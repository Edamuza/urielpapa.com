# Tool pages queue

A tool page (`/stack/<tool>`) is built once its Stack entry (`src/content/stack/<tool>.yaml`) has an `about` text. The tool-pages task writes them in this order: the tools the site writes about most, and where Uriel's use is recorded, come first. Pricing needs its source and the date it was checked; `changelog` turns on release notes for the tool.
