# Glossary queue

The glossary task takes the first lines with status `queued`. A term that already has its own explainer post (for example tokenization, context window, llms.txt, semantic SEO, GEO and AEO) is left out: the post is the page for it, and a glossary entry would compete with it. The build blocks a term whose "What is …" post already exists.
