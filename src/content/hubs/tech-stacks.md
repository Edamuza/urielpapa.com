A tech stack is the set of languages, frameworks, databases and services a system is built on. Here I write about what is happening to frameworks and databases, the new tools I try, and the architecture, testing and hosting choices behind real projects.

The stacks I have worked with cover a lot of ground. The [VITE SEO Digital Advertising ERP](/projects/vite-seo-erp) used a Laravel 13 API, a Next.js 16 and React 19 front end, and MySQL. [TravelEase](/projects/travelease), my capstone thesis, used React 19, TypeScript, Vite and Tailwind CSS 4 on the front end, Node.js, Express, Prisma, PostgreSQL and Supabase Auth on the back end, Redis for caching and rate limiting, and 411 Vitest tests, deployed on Vercel and Railway. The [client quotation portal](/projects/quotation-portal) ran on Next.js 14, Prisma and PostgreSQL with Playwright for PDFs, and the [NFC card platform](/projects/nfc-card-platform) on Laravel 13 and Tailwind CSS. On mobile, I co-developed [Tell Liora](/projects/tell-liora) with Expo and React Native.

This site is built with Astro, Tailwind CSS and Keystatic, a git-based CMS, so posts about it double as notes from a working build.

Framework details change fast, so posts here carry their dates and get reviewed when new versions land.
