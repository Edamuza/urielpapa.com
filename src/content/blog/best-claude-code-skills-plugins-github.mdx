The best open-source Claude Code skills and plugins on GitHub are Superpowers for a full plan-then-test workflow, Anthropic's own skills repo for document work and reference code, and GitHub's Spec Kit for building from a written spec. All three are free and were updated in November 2026. Claude-Mem adds memory between sessions, and wshobson/agents is a large catalog you install one plugin at a time.

This review is part of my [AI, in Depth](/topics/ai "AI, in Depth: Uriel Papa's articles on AI") writing. I built a multi-agent Claude Code pipeline that audits a production codebase in under 6 minutes, so I care about what a plugin adds to every session, not only what it promises.

## How did I choose these repos?

I judged every repo on the same five checks, against the GitHub API and each README on November 14, 2026:

- **Free and open:** an open-source license, or a README that says which parts are open.
- **Active:** a push to the repository in November 2026.
- **Real Claude Code support:** a documented install path for Claude Code, not only a mention.
- **Stars:** a popularity signal only. Stars do not prove a skill works in your project.
- **Not covered before:** I left out the SEO skills from my review of [open-source SEO and GEO tools on GitHub](/blog/open-source-seo-geo-tools-github "The best open-source SEO and GEO tools on GitHub") and the n8n skills from my [free n8n workflow templates](/blog/free-n8n-workflow-templates-github "Free n8n workflow templates on GitHub") post.

## Which Claude Code skills and plugins are worth installing?

Five repos passed. Each one gets the same checks.

### Superpowers

[obra/superpowers](https://github.com/obra/superpowers "Superpowers on GitHub") is a set of skills that its README calls "a complete software development methodology for your coding agents".

- **Who it's for:** builders who let Claude Code work on its own for long stretches and want it to plan and test first.
- **What's inside:** skills for brainstorming, writing plans, git worktrees, test-driven development, systematic debugging, code review and finishing a branch. They trigger on their own, so the agent asks what you want before it writes code.
- **Cost:** free. Prime Radiant, the company behind it, offers paid enterprise support.
- **License and activity:** MIT, about 317,000 stars, last push November 3, 2026. Built by Jesse Vincent.
- **Watch out for:** the test-driven skill "deletes code written before tests", so do not point it at a half-written branch you want to keep. The optional visual companion loads a logo that reports the Superpowers version. `SUPERPOWERS_DISABLE_TELEMETRY` turns it off.

Superpowers installs with `/plugin install superpowers@claude-plugins-official`, from Anthropic's own marketplace.

### Anthropic's skills repo

[anthropics/skills](https://github.com/anthropics/skills "Anthropic's skills repository on GitHub") is Anthropic's public collection of example skills, plus the template and spec for writing your own.

- **Who it's for:** anyone who wants document skills in Claude Code, or a clean example before writing a first skill.
- **What's inside:** creative, design, developer and enterprise example skills, and the docx, pdf, pptx and xlsx skills "that power Claude's document capabilities". Install with `/plugin marketplace add anthropics/skills`, then pick `document-skills` or `example-skills`.
- **Cost:** free. The same example skills are already in paid Claude.ai plans.
- **License and activity:** the README says many skills, including the four document skills, are Apache 2.0. GitHub shows no single license for the repo, so check each skill folder. About 194,000 stars, last push November 6, 2026.
- **Watch out for:** the README says the skills are "for demonstration and educational purposes only" and may behave differently from what Claude does. Test them before you rely on them.

### Spec Kit

[github/spec-kit](https://github.com/github/spec-kit "GitHub Spec Kit on GitHub") is GitHub's toolkit for spec-driven development: you write what to build and why, then the agent turns it into a plan, tasks and code.

- **Who it's for:** people who already write specs, or who want the agent to stop guessing on bigger features.
- **What's inside:** the `specify` CLI and skills such as `/speckit-specify`, `/speckit-plan`, `/speckit-tasks` and `/speckit-implement`, plus extensions for bug fixing and idea assessment. The [Claude Code integration page](https://github.com/github/spec-kit/blob/main/docs/integrations/claude.md "Spec Kit's Claude Code integration guide") installs them as `.claude/skills/speckit-*`.
- **Cost:** free. It needs Python 3.11 or later and uv.
- **License and activity:** MIT, about 150,000 stars, last push November 12, 2026. Maintained by GitHub.
- **Watch out for:** its catalogs include community extensions, and the README says listings "are not audits or endorsements". Review that code first.

I built my [job and client matching CRM](/projects/job-client-crm "Job and Client Matching CRM case study") by directing AI agents against a written spec, and that is the habit Spec Kit makes formal.

### Claude-Mem

[thedotmack/claude-mem](https://github.com/thedotmack/claude-mem "Claude-Mem on GitHub") gives Claude Code memory between sessions: a second agent takes notes while you work, and the next session starts with a short index of them.

- **Who it's for:** people who return to the same codebase daily and are tired of re-explaining it.
- **What's inside:** hooks that pass each tool call to a local worker, SQLite storage in `~/.claude-mem`, and three MCP search tools. It works with Claude Code, Codex, Cursor, OpenCode and 11 more agents.
- **Cost:** the code is free. After sign-in, the installer offers a hosted observer with a 30-day free trial that asks for a payment method. You can instead use your own OpenRouter or Gemini key, or your Anthropic plan.
- **License and activity:** Apache 2.0, about 117,000 stars, last push November 13, 2026. Built by Alex Newman under the thedotmack account.
- **Watch out for:** anonymous usage analytics are on by default, and `npx claude-mem telemetry disable` turns them off. Wrap secrets in `<private>` tags so they are never stored.

### wshobson/agents

[wshobson/agents](https://github.com/wshobson/agents "wshobson/agents plugin catalog on GitHub") is one large catalog of plugins, subagents, skills and commands, written once in the Claude Code plugin format.

- **Who it's for:** developers who want a ready-made specialist, such as a Python, security or code review plugin.
- **What's inside:** 94 plugins holding 202 agents, 185 skills and 105 commands. Add the marketplace with `/plugin marketplace add wshobson/agents`, then install only the plugins you need.
- **Cost:** free.
- **License and activity:** MIT, about 42,500 stars, last push November 9, 2026. Maintained by Seth Hobson.
- **Watch out for:** its own README says the LLM judge scores in its evaluation tool "do not prove that a task succeeds in a project". Installing everything would also crowd Claude's context.

## What is the difference between a skill, a plugin and a subagent?

A Claude Code skill is a folder with a `SKILL.md` file of instructions that Claude loads when a task matches its description. A plugin is a bundle that installs several skills, subagents, hooks or MCP servers as one unit, according to Claude Code's [plugins overview](https://code.claude.com/docs/en/plugins "Claude Code plugins overview"). A subagent is a separate Claude instance that a plugin or skill can hand work to, with its own context window.

The difference matters for cost. The plugins overview says the name and description of every skill and agent that Claude can call on its own sit in Claude's context on every turn, "even in sessions where nothing from the plugin runs". The full text loads only when used.

So a small, focused plugin is cheaper than a catalog. My explainer on [tokenization](/blog/what-is-tokenization "What is tokenization in AI?") shows why every extra line of context has a price.

## How do you install a third-party plugin safely?

A Claude Code plugin runs with your user privileges, whichever marketplace it comes from. The plugins overview puts it plainly: "a plugin you install can run code with your user privileges". Before you install any of these:

- **Prefer Anthropic's marketplaces when you can.** Claude Code accepts the official names, such as `claude-plugins-official`, only for marketplaces in Anthropic's own GitHub organization. Superpowers is there.
- **Read the hooks and scripts,** not only the skill text. Claude-Mem, for example, runs a hook on every tool call.
- **Check `allowed-tools`.** The [skills documentation](https://code.claude.com/docs/en/skills "Claude Code skills documentation") says this field lets Claude use the listed tools without asking during that turn.
- **Turn off telemetry you did not ask for,** using the flags above.

## Which one should you start with?

Start with the problem you have today:

- **The agent jumps into code too fast:** Superpowers, from the official marketplace.
- **You build bigger features from a brief:** Spec Kit, with `specify init my-project --integration claude`.
- **You need Word, PDF, PowerPoint or Excel output:** the `document-skills` plugin from Anthropic's repo.
- **You keep re-explaining the same codebase:** Claude-Mem, set up with your own provider and telemetry off.
- **You want one specialist, such as Python or security:** a single plugin from wshobson/agents.

Install one, use it for a week, then decide on the next. If you are still learning how agents work, my list of [free GitHub repos to learn AI agents](/blog/free-github-repos-to-learn-ai-agents "Free GitHub repos to learn AI agents") is the better first stop.
