If you pay for the OpenAI API, jobs that can wait a few hours now cost less. On November 17, 2026, according to [OpenAI's API changelog](https://developers.openai.com/api/docs/changelog "OpenAI's API changelog entry for completion windows"), OpenAI added 2-hour and 8-hour completion windows to background mode in the Responses API, at 30% and 40% below Standard token rates. For a small team running reports, product descriptions or data clean-ups, that is a quick saving.

This take is part of my [AI, in Depth](/topics/ai "AI, in Depth articles") writing. My take on [GPT-6 Sol and Luna](/news/gpt-6-sol-luna "GPT-6 Sol and Luna: OpenAI's cheaper GPT-6 models in the API") covers the model prices these discounts start from, and [what tokenization is](/blog/what-is-tokenization "What tokenization is and how AI pricing works") explains how token prices add up.

## What happened?

OpenAI's [background mode guide](https://developers.openai.com/api/docs/guides/background "OpenAI's background mode guide") now lists three completion windows: `soonest`, the default with no discount, `2h` at "30% below Standard", and `8h` at "40% below Standard". The guide says "Discounted completion windows are in public beta on GPT-6.2 Astra, GPT-6.2 Sol, GPT-6.1 Terra, and GPT-6 Luna."

## What changed?

OpenAI's [pricing page](https://developers.openai.com/api/docs/pricing "OpenAI API pricing") lists Standard rates per million tokens of US$2 input and US$10 output for GPT-6.2 Sol, and US$8 input and US$40 output for GPT-6.2 Astra. By my own calculation from those rates, the 8-hour window brings Sol to US$1.20 input and US$6 output, and Astra to US$4.80 and US$24.

The guide sets a few conditions:

- **Standard processing only:** "Set `service_tier` to `default` to select Standard."
- **Follow-ups count too:** "The discount applies to model token rates on each eligible request, including follow-ups."
- **Shared limits:** 2h and 8h requests "share the Batch/Background Rate Limit with Batch API jobs."
- **Storage:** background mode "temporarily stores response data even when you set `store` to `false` or use Zero Data Retention."

## What does it mean for businesses and founders?

My read is that this rewards sorting your AI work by urgency. A customer chat needs an answer now. A nightly sales summary, a batch of Shopee or Lazada product descriptions, or tagging last month's leads can wait until morning, and now pays less for waiting.

Two cautions. It is a beta, so test it on one job before moving everything. And check the storage note if you handle customer data under the Data Privacy Act, because background mode keeps response data for a while even with storage turned off.

## What should you do now?

1. **List your API jobs** and mark which ones nobody waits on.
2. **Move one of them** to background mode with `completion_window` set to `8h`.
3. **Compare a week of costs** on your usage dashboard.
4. **Keep live chat on the default window.**
