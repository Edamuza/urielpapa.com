## The problem

When a site needs rebuilding, the old pages, their images and their fonts are the starting point. Sometimes the only copy left is on the Wayback Machine, and saving it page by page by hand is slow.

It started with a client rebuild where the old site was already offline and the only copy left was on the Wayback Machine. Saving every page and image by hand took far too long, so we wrote a tool to do it.

## What we built

- **A multi-threaded command-line tool** that saves web pages, including Wayback Machine snapshots.
- **Assets included:** each page comes down with its images and fonts.
- **A WordPress theme layout** for the saved files.
- **A WordPress block child theme base** packaged with the tool, for bringing the saved pages into WordPress.

## Stack and why

- **Tool:** Python.
- **Target:** WordPress, through a block child theme base.

Python is quick to write for scraping and file handling, and threads made it practical to save many pages at once. The output targets WordPress because that's where most of our client rebuilds landed, so a ready block child theme saved setup time on every project.

## Results

- Pages and snapshots saved with their images and fonts, in a layout ready for a WordPress rebuild.

- Used on the agency's own site rebuilds. I haven't kept an exact count of the pages it has saved.
