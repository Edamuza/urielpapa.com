## The problem

SEO work on WordPress repeats the same checks and the same publishing steps on every site: headings, indexability, images, broken links, internal links, titles, descriptions and schema. Doing it by hand takes time, and a missed step goes live.

[Uriel to add: the moment it became clear these tools were needed]

## What we built

Five plugins, about 11,700 lines of code in total:

- **An SEO diagnostic scanner** with content, heading, indexability, image and broken-link checks, plus spreadsheet exports.
- **An internal-link content graph** that shows how pages link to each other.
- **A publish guard** that requires an SEO title, a meta description and schema before a post can go out.
- **Bulk importers** for DOCX drafts and for schema CSV files.
